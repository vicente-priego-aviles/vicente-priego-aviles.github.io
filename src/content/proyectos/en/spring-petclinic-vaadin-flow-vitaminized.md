It starts from the Vaadin Flow implementation of the classic Spring PetClinic and extends it. The new features were developed by the Devin AI agent in pull requests that I reviewed and merged.

**What it adds**
- Medical records for pets.
- An appointment system with a calendar view, filters and a link in the main menu.
- Translations for all the new views.
- Javadoc and comments on the core classes, plus tests for the vaccination scheduler and the owner service.
- Move to Java 21.
