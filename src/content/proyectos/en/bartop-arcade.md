My tabletop arcade machine: a Raspberry Pi 3 running RetroPie with a two-player Xin-Mo panel. I keep the catalogue of tested games in an Obsidian vault, and a Python script (`_scripts/generar_web.py`) generates the website from it.

It contains no ROMs; game covers, names and trademarks belong to their owners.
