Mi máquina recreativa de sobremesa: una Raspberry Pi 3 con RetroPie y un panel Xin-Mo para dos jugadores. El catálogo de juegos probados lo llevo en una bóveda de Obsidian, y un script de Python (`_scripts/generar_web.py`) genera la web a partir de ella.

No contiene ROMs; las portadas, nombres y marcas de los juegos pertenecen a sus propietarios.
